# PRAS-BPLE — 전력수급기본계획 시뮬레이터

제1차(2002)부터 제11차(2025)까지 11개 전력수급기본계획의 수요전망·설비계획·전원구성을
원문 수치로 비교하고, 수요·예비율·전원구성·이용률 전제를 바꿔 설비 과부족과 발전량·
온실가스 배출을 다시 계산합니다.

`pras-der` 저장소에 편입하는 방법은 [`INTEGRATION.md`](INTEGRATION.md) 를 보세요.
`kepco-stat/`·`ember-sim/` 과 같은 **루트 직속 정적 폴더**로 실려 `/bple/` 에서 열립니다.
단독으로 열어볼 때는 `bple/index.html` 을 브라우저로 열면 됩니다.

범례를 누르면 해당 계열이 사라지고 다시 누르면 돌아옵니다(전원구성·발전량은 숨긴 전원을
빼고 비중을 다시 계산합니다).

전원구성 비교·역대 제원 표·오차 막대·차수 선택은 모두 **최근 차수(11차)부터** 내려갑니다.
시나리오 바로 아래에 11차 원안이 오도록 한 배치입니다.

## 시나리오와 계획 원안

화면의 **시나리오**는 「01 분석 조건」에 입력된 값으로 계산한 결과이고, **제N차**는 그
계획이 공표한 원안입니다. 차수를 고르면 그 원안이 분석 조건에 그대로 적재되므로, 아무것도
건드리지 않으면 둘은 같은 값입니다. 조건을 하나라도 바꾸면 KPI 머리말과 전원구성 막대의
라벨이 `원안 그대로` → `원안에서 수정됨` 으로 바뀝니다.

「05 전원구성 비교」에서는 시나리오 막대를 **선택한 차수 바로 위**에 끼워 넣습니다.
제10차를 고르면 제11차 아래·제10차 위에, 제5차를 고르면 제6차 아래·제5차 위에 놓이므로
원안과 곧바로 견줄 수 있습니다. 짝이 되는 원안 행은 라벨을 굵게 표시합니다.

조작 버튼은 **계획 원안으로** 하나입니다. 수요·예비율·전원구성·이용률·혼소율을 선택한
차수의 공표값으로 한 번에 되돌립니다.

설비 과부족을 설비 규모로 가늠하는 값은 버튼이 아니라 KPI 에 상시 표시합니다.
`신규 필요설비` 타일의 부제가 현 구성비 기준 **정격 환산치**를 함께 보여줍니다.

```
신규 필요설비  −3.4 GW
목표설비 대비 부족분 · 현 구성비로 정격 5.7GW 상당
```

11차 구성비에서는 정격/실효가 약 1.69배(268.2 ÷ 158.3)입니다. 재생에너지 피크기여도가
11.1% 라 정격이 커도 실효로는 조금만 잡히기 때문이며, 이 배율이 부제에 그대로 반영됩니다.

어느 전원을 얼마나 지을지는 이 숫자가 답하지 않습니다. 실제 전기본의 신규설비 배분
(11차의 열병합 2.2GW · SMR 0.7GW · 대형원전 2.8GW 등)은 건설기간·입지·정책이 걸린 별도
판단이라 전원구성 칸을 직접 조정해야 합니다.

## 수요 산정 사슬과 11차 모형수요 0.1 보정

11차는 추가수요와 수요관리를 따로 떼어 더하고 빼는 구조입니다.

```
모형수요 128.8 + 추가수요 16.8 = 기준수요 145.6 − 수요관리 16.3 = 목표수요 129.3 GW
```

KPI 첫 칸은 **목표수요**이고 입력칸의 **모형수요**는 그 앞 단계이므로 두 값이 다릅니다.
이 사슬은 입력 그리드 바로 아래에 한 줄로 표시됩니다.

11차 참고1 표의 공표 모형수요는 **128.9GW** 인데, 계획이 항목별로 따로 반올림해
`128.9 + 1.4 + 4.4 + 11.0 = 145.7` 로 표의 합계 `145.6` 과 0.1 어긋납니다
(2025·2027·2030·2036년 행도 같습니다). 시뮬레이터는 **공표 기준수요 145.6 과 목표수요
129.3 이 정확히 떨어지도록** 모형수요를 128.8 로 역산해 씁니다. 반대로 128.9 를 그대로
넣으면 기준수요 145.7 · 목표수요 129.4 가 되어 계획의 대표값 두 개가 모두 어긋납니다.
이 보정은 화면의 사슬 설명에도 밝혀 둡니다.

추가수요·수요관리를 분리하지 않은 1~10차는 모형수요가 곧 목표수요입니다.

## 진단 · 민감도 · 역산

물량 균형만 보여주면 "숫자만 바뀐다"에 그치므로, 계산 결과를 해석하는 층을 따로 두었습니다.
모두 검증된 기존 모델의 미분·역산이라 새 가정이 들어가지 않습니다.

### 경고 (「02 산정 결과」 하단)

전제가 기준을 벗어나면 심각도별로 알립니다.

| 조건 | 심각도 | 내용 |
|------|--------|------|
| 실효용량 < 목표설비 | bad | 미달량, 실현 예비율, 현 구성비 기준 필요 증설 정격 |
| 배출량 > 감축경로 | bad | 초과량과 초과율 |
| 배출량이 경로에 밀착 | info | 여유가 없어 조정 여지가 없음을 알림 |
| 정격 합계가 원안과 차이 | warn(±10% 이상) / info | 차이 GW·%, 가장 크게 움직인 전원 |
| 이용률 92% 초과 | warn | 예방정비·고장정지 감안 시 실현 곤란 |

치명적 경고가 없으면 맨 앞에 충족 메시지를 둡니다.

### 레버별 민감도 (「07 진단」)

9개 레버를 한 단위씩 움직여 목표설비·실효용량·과부족·발전량·무탄소비중·배출량의 변화를
표로 보여주고, 공급력과 배출에 가장 효과가 큰 레버를 자동으로 짚습니다.
11차 기본값에서는 이런 결과가 나옵니다.

| 조정 | 목표설비 | 실효용량 | 발전량 | 배출 |
|---|---|---|---|---|
| 기준 예비율 +1%p | +1.3GW | — | — | — |
| 수요관리 +1GW | −1.2GW | — | — | — |
| 재생e 피크기여도 +1%p | — | +1.2GW | — | — |
| 재생e 정격 +10GW | — | +1.1GW | +16.9TWh | — |
| 석탄 이용률 +1%p | — | — | +1.9TWh | +1.2백만톤 |
| 석탄 암모니아 혼소 +10%p | — | — | — | −10.8백만톤 |

재생e 피크기여도 1%p 가 재생e 정격 약 11GW 와 맞먹는다는 점이 바로 드러납니다.

### 감축경로 역산

다른 전제를 고정한 채 한 항목만 바꿔 감축경로에 정확히 닿게 하는 값을 풉니다.
석탄 이용률을 70% 로 올린 경우:

```
배출 113.3백만톤 > 경로 83.1백만톤
→ 석탄 이용률 45.6% / 암모니아 혼소율 47.9% / 석탄 정격 14.4GW 중 하나
```

석탄을 모두 멈춰도 LNG 만으로 경로를 넘으면 LNG 수소 혼소율로 전환해 풉니다.
경로를 이미 충족 중이면 같은 값이 **여기까지는 늘려도 되는 한계값**으로 제시됩니다.

> 비용(건설비·연료비·탄소비용)은 의도적으로 넣지 않았습니다. 별도 시뮬레이터로 분리할
> 예정입니다. 참고로 원문에서 확인되는 단가는 배출권 25,000원/tCO₂e(7차), 환경비용
> 석탄 19.2원/kWh·LNG 8.2원/kWh(8차)이며, 건설단가는 차수별로 집계 범위가 달라
> kW당 단가를 일관되게 뽑기 어렵습니다.

## 산정식

제11차 전기본 「발전설비 계획 수립절차」를 그대로 따릅니다.

```
기준수요   = 모형수요 + 추가수요(첨단산업 + 데이터센터 + 전기화)
목표수요   = 기준수요 − 수요관리량
목표설비   = 목표수요 × (1 + 기준 설비예비율)
실효용량   = Σ (전원별 정격용량 × 피크기여도)
신규필요설비 = 목표설비 − 실효용량
발전량     = 정격용량 × 이용률 × 8.76
청정수소·암모니아 = 석탄발전량 × 암모니아혼소율 + LNG발전량 × 수소혼소율
배출량     = (석탄 순발전량 × 0.8384 + LNG 순발전량 × 0.3800) × 0.948
```

### 계수의 출처

| 계수 | 값 | 출처 |
|------|-----|------|
| 석탄 배출계수 | 0.8384 tCO₂eq/MWh | 11차 전기본, '20~'22년 발전기별 실적 평균 |
| LNG 배출계수 | 0.3800 tCO₂eq/MWh | 같음 |
| 전환부문 보정계수 | 0.948 | 아래 검증 참조 |
| 피크기여도 | 계획별 상이 | 각 계획 본문의 실효/정격 비율에서 역산 |
| 이용률 | 계획별 상이 | 각 계획의 전원별 발전량 ÷ (정격용량 × 8.76) |

보정계수 0.948 은 열병합·자가발전 배분 등으로 생기는 단순 곱셈과의 차이를 메우는 값입니다.
11차의 배출목표 두 지점에 맞춰 역산한 뒤, 세 번째 지점에서 독립 검증했습니다.

| 검증 지점 | 모델 | 계획 공표치 | 오차 |
|-----------|------|-------------|------|
| 11차 2030년 | 145.8 | 145.9 백만톤 | 0.1% |
| 11차 2038년 | 83.1 | 83.1 백만톤 | 0.0% |
| 10차 2036년 | 98.7 | 98.8 백만톤 *(11차가 인용한 10차 감축목표)* | 0.1% |

| 전역 | 내용 |

| `SRC` | 11개 계획 공통 비교용 8개 전원 분류 |
| `ENGINE` | 피크기여도·이용률 기본값, 배출계수, 보정계수, 혼소율 |
| `ACTUAL` | 각 계획 본문에 '실적'으로 명시된 최대전력·설비용량 |
| `PLANS` | 차수별 계획기간·수요전망·예비율·설비·발전량·해설 |
| `DSM11` | 11차 수요관리 목표 16.3GW |
| `ADD11` | 11차 추가수요 ('38년 최대전력 증분) |

각 계획 항목의 주요 필드:

```js
{
  id: 11, name: '제11차', year: '2025.2',
  period: [2024, 2038], target: 2038,
  reserve: '22% (단기 20 / 중기 21 / 장기 22)', reserveNum: 22,
  peak:        { 2024: 101.0, ... },   // 목표수요 최대전력 (헤드라인 기준)
  peakWinter:  { ... },                // 동계 계열 (10·11차)
  peakSummer:  { ... },                // 하계 계열 (8·9차)
  peakBase:    { ... },                // 기준수요 (11차)
  reserveSeries: { ... },              // 계획 원문 연도별 설비예비율
  pc:   { renew: 11.1, coal: 98.2, other: 97.0 },  // 피크기여도 override
  blend: { nh3: 20, h2: 26.1 },        // 혼소율
  cap:  { nuclear: 35.2, ... },        // 목표연도 정격용량
  gen:  { nuclear: 248.3, ... },       // 목표연도 발전량 (없으면 null)
  genH2: 43.9,                         // 청정수소·암모니아 발전량
}
```

새 차수가 나오면 `PLANS` 배열에 항목 하나를 더하면 됩니다. 화면·차트·표는 모두 이
배열을 순회하므로 다른 파일은 건드릴 필요가 없습니다.

## 출처

본문·별첨 표에서 직접 옮겼으며, 추정값은 위에 명시한 경우로 한정됩니다.

# PRAS-LOAD — 전력소비패턴·요금 진단 시뮬레이터 (`pras-load/`)

계약종·업종·지역별 시간별 사용량(2016~2022)으로 전력소비패턴을 분해하고, 2021~2026년 전기요금표
14개 판을 적용해 요금체계의 정합성과 고객·한전 간 재무적 형평성을 시뮬레이션합니다.
`kepco-stat/`·`bple/` 과 같은 **루트 직속 정적 폴더**로 `/pras-load/` 에서 열립니다.

## 화면 구성

| 섹션 | 내용 |
|---|---|
| 01 분석 조건 | 차원(계약종 33 / 산업종 79 / 본부 15 / 중분류×산업종 / 중분류×본부), 연도·계절·날짜유형, 시간대(기존/2026 개편) |
| 02 부하패턴 | 평균 일부하곡선(연도 겹쳐보기, 시간대 음영), 월×시간 히트맵, 부하모양 변화(정규화 차이) |
| 03 패턴 변화 | 한낮·저녁·최대부하 비중 추이, 전년 대비 부하모양 변화율 표, 일별 사용량(장애일 표시), 표본 비중 |
| 04 요금 진단 | 같은 부하에 요금표 7개 시점 적용한 계약종별 평균단가, 2026 개편 영향, 원가 회수 추이(한국전력통계) |
| 05 요금 시뮬레이터 | 요금표·시간대·대분류별 조정 → 계약종별 수입·단가·원가 회수율, 실적 보정, 시간대·전압별 원가 가중 |
| 06 데이터·방법 | 보정 내역, 요금표 판본별 추출 방법, 가정과 미해결 항목 |

## 파일 구성

| 경로 | 내용 |
|---|---|
| `index.html` | 배포 파일(글꼴·CSS·JS 내장). 데이터는 `data/` 에서 불러옴 |
| `data/*.json` | 배포용 집계 데이터(약 11MB). 산업종·교차 집계는 해당 차원을 고를 때만 불러옴 |
| `src/app.html` | 화면·계산 원본. 수정은 여기서 |
| `scripts/build_data.py` | 원자료(parquet) → 집계 큐브·일별·8760시간·보정 내역 |
| `scripts/build_ref.py` | `kepco-stat/build/data.json` → 대분류별 판매량·수입·호수·요금적용전력·원가 |
| `scripts/analyze.py` | 부하율·피크·시간대 비중·평균단가 사전 계산 |
| `scripts/tariff/` | 요금표 PDF → `tariffs.json` (추출 `rows/blocks/extract`, 스캔·양식불일치 판본 확정 `infer/anchor`, 조립 `assemble`) |
| `scripts/build_page.py` | `src/` + `build/` → `index.html`, `data/` |

## 다시 만들기

원자료는 저장소에 넣지 않습니다(연도별 CSV 약 400~700MB).

```bash
# 1) 원본 CSV(cp949) → parquet : year=YYYY.parquet
# 2) 집계
python3 scripts/build_data.py <parquet_dir> build          # pandas, pyarrow, holidays
python3 scripts/build_ref.py ../kepco-stat/build/data.json build
# 3) 요금표 (PDF 폴더 기준, scripts/tariff/ 안에서 실행; pdftotext·tesseract(kor) 필요)
#    rows.py → extract.py(정확 판본) → infer.py → anchor.py → assemble.py ../../build/tariffs.json
# 4) 분석·페이지
python3 scripts/analyze.py build
python3 scripts/build_page.py ../ember-sim/index.html
```

## 데이터 기준과 보정

- 원자료: 계약종×본부×산업종×날짜, H01~H24 (kWh, **H01 = 00~01시**). 2016~2022년 20,065,459행.
- **수집장애일 58일**(2020년 3월 전후 41일 집중): 결측비중 > 3%, 행 수 < 이동중앙값 90%,
  또는 같은 날짜유형 11일 이동중앙값 대비 총량이 평일·토 0.8~1.2배 / 일·공휴일 0.6~1.4배 밖.
  해당 일은 같은 조합·같은 달·같은 날짜유형 유효일 평균곡선으로 대체. 일부 시간만 빈 행은 그 시간만 채움.
  그 달 유효일이 50% 미만인(드문드문 들어오는) 조합은 실제 들어온 행만 반영. 보정량은 연 +0.01~0.42%, 2020년 +2.8%.
- **표본 비중**: 시간별 데이터는 스마트미터 계량분. 한국전력통계 판매량 대비 주택용 50→80%,
  일반용 58→72%(2016→2022). 크기 비교에는 확대계수, 모양 비교에는 정규화를 씁니다.
- 날짜유형: 평일 / 토요일 / 일요일·공휴일(`holidays.KR`, 대체공휴일 포함).

## 요금표

- 14개 판(2021.1.1 ~ 2026.4.16). 글자층이 온전한 6개 판은 직접 추출.
- 스캔본(2022.4·7·10, 2023.1, 2023.11)과 양식이 다른 판(2023.5, 2024.1·4)은 **2021.1과 2024.7 정확 판본 사이
  총 인상분을 앵커**로 두고, 단계별 인상분 경로를 문서 숫자(OCR/글자층)와 대조해 확정. 51개 묶음 모두 확정.
  확인된 단계: 2022.4 +4.9 / 2022.10 +7.4(을 대용량 +11.9·+16.6) / 2023.1 +11.4 / 2023.5 +8.0 /
  2023.11 산업용(을) +6.7·+13.5 / 농사용 분할 인상(1월 +3.8, 4·5월 +2.7).
- 2026.4.16 시간대 개편(산업용(을)·EV 4.16, 그 외 6.1): 경부하 22~08시, 최대부하 여름·봄가을 15~21시,
  겨울 9~12·16~19시. 산업용(을) 봄·가을 주말·공휴일 11~14시 50% 할인.
- 2021.1 이전(2016.12~2020.12)은 2021.1 전력량요금 + 5.3원(기후환경요금 분리 전)으로 재구성.

## 한계와 다음 단계

- 고압 선택요금(Ⅰ/Ⅱ/Ⅲ) 가입 비중이 없어 선택Ⅱ를 대표로 사용.
- 기본요금은 대분류 요금적용전력을 계약종 평균일 최대부하 비율로 배분한 추정치.
- 주택용 누진은 호당 사용량 로그정규 분포 가정 → 실적 보정으로 수준을 맞춤. 조합별 호수 확보 시 대체.
- 원가는 현재 총괄원가 단가(영업비용÷판매량)에 시간대·전압 계수를 곱한 임시 구조.
  **SMP·계통부하 시간별 자료 연계 후 시간대별 원가배분으로 교체 예정.**
- 임시전력(갑/을저압)·가로등(갑)은 요금표에 단가가 없어 미산정.

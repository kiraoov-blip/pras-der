# PRAS-LOAD — 전력 사용 패턴·요금제 진단 시뮬레이터 (`pras-load/`)

용도(계약종)·업종·지역별 시간별 사용량(2016~2025)으로 사용 패턴을 분석해
① 현행 요금제가 원가를 공정하게 나누는지, ② 요금 개편이 바뀐 사용 패턴을 반영하는지,
③ 한전 재무와 계통에 어떤 영향이 있는지 진단하고, ④ 요금제 개편 방향을 제안합니다.
`kepco-stat/`·`bple/` 과 같은 **루트 직속 정적 폴더**로 `/pras-load/` 에서 열립니다.

## 화면 구성 (상단 탭)

| 탭 | 내용 |
|---|---|
| 개요 (`#overview`) | 네 가지 질문 카드 — 공정성(전체 평균 대비 회수율·정책 보조), 요금 신호(피크 이동·2026 시간대 개편·배율), 재무·계통(부채비율·금융원가·연료비 미회수·전력자급률), 제안(개선안 3개, '열기'로 시뮬레이터에 바로 적용) |
| 사용량·패턴 (`#usage`) | 분석 조건(차원: 계약종 33 / 산업종 79 / 본부 15 / 중분류×산업종·본부, 연도·계절·날짜유형·시간대), 부하패턴(일부하곡선·히트맵·모양 변화), 패턴 변화(한낮·저녁·최대부하 비중, 변화율, 일별, 표본 비중), 계약종·규모·본부별 판매실적, 시도별 판매실적·전력자급률 |
| 요금제 진단 (`#diag`) | 진단 요약, ① 현행 요금표 기준 대분류 회수율(전체 평균 = 100)과 원가 회수 추이, ② 같은 부하에 요금표 판본을 적용한 평균단가·2026 개편 영향, SMP·피크로 본 원가 신호와 요금 배율 |
| 개선안 시뮬레이터 (`#sim`) | 개선안 불러오기·요금표·기준 연도 → 대분류별 조정 → 수입·단가·회수율 KPI, 회수율 차트, 형평성 진단. 계약종별 상세 표와 '고급 설정'(시간대·주택용 분포·할인·보정·연료비·원가 배분 가정)은 접어 둠 |
| 심화 분석 (`#deep`) | 하위 탭: 주택용 누진·복지할인 / 연료비 연동(+월별 판매단가·정산단가) / 지역별 요금제(산업용 시나리오) / 한전 재무 |
| 데이터·방법 (`#data`) | 보정 내역, 요금표 판본별 추출 방법, 가정과 미해결 항목 |

- 예전 앵커(`#s-sim` 등)로 들어오면 해당 탭이 열립니다. 탭을 열 때 그 탭의 차트만 다시 그립니다.

## 파일 구성

|---|---|
| `index.html` | 배포 파일(글꼴·CSS·JS 내장). 데이터는 `data/` 에서 불러옴 |

| `scripts/analyze.py` | 부하율·피크·시간대 비중·평균단가 사전 계산 |

| `scripts/build_sysload.py` | 계통부하·태양광 엑셀 → `sysload_hourly.parquet` (항등식 점검) |
| `scripts/build_monthly.py` | 전력통계월보(속보) 엑셀 129호 → `monthly.json` (계약종 대분류 월별 판매량·호수·수입, 정산단가, 수급, 태양광, 시도·산업분류) |
| `scripts/build_regionmap.py` | 본부 ↔ 시도 10개 권역 대응(한전 조직표 기준), 권역별 표본 비중 → `region_map.json` |
| `scripts/build_network.py` | 송배전 이용요금 총괄원가(송전·배전, 적정원가·적정투자보수, 배전 저압·고압 단가) → `network.json` |

| `scripts/build_contract.py` | 계약종별 판매실적(2022~2025 월별, 본부 × 계약전력구간 × 계약종) → `contract.json` (월보 대조) |
| `scripts/build_fin.py` | 한전 별도 재무상태표(분기 PDF 2016.1Q~2026.1Q) + 한국전력통계 34·35(연결 손익·재무상태) → `fin.json` |
| `scripts/build_region.py` | 시도·시군구별 판매실적(2016~2025 연간) + 한국전력통계 8-2 시도별 발전설비·발전량(2018~) → `region.json` |
| `scripts/build_resbins.py` | 주택용 전체 가구 사용량 구간별 분포(2025 월별, 저/고압 × 일반·단일·종합) → `res_bins.json` (요금표 검증·하계 비중 포함) |
| `scripts/build_welfare_bins.py` | 복지할인 가구 사용량 구간별 분포(2025 월별, 저/고압 × 일반·단일·종합) → `welfare_bins.json` |
| `scripts/build_fuel.py` | 연료비조정단가 산정내역(분기 PDF 텍스트) → `fuel.json` (필요·규칙·적용 단가, 원 게시값) |
| `scripts/analyze_cost.py` | SMP·계통부하 × 계약종 부하 → `cost.json` (SMP 큐브, 시간대별 SMP, 피크 기여, 태양광) |
| `scripts/tariff/` | 요금표 PDF → `tariffs.json` (추출 `rows/blocks/extract`, 스캔·양식불일치 판본 확정 `infer/anchor`, 조립 `assemble`) |
| `scripts/build_page.py` | `src/` + `build/` → `index.html`, `data/` |

## 다시 만들기

원자료는 저장소에 넣지 않습니다(연도별 CSV 약 400~700MB).

```bash
# 1) 원본 CSV(cp949) → parquet : year=YYYY.parquet
# 2) 집계
python3 scripts/build_data.py <parquet_dir> build          # pandas, pyarrow, holidays
python3 scripts/build_ref.py ../kepco-stat/build/data.json build
# 3) 요금표 (PDF 폴더 기준, scripts/tariff/ 안에서 실행; pdftotext·tesseract(kor) 필요)
#    rows.py → extract.py(정확 판본) → infer.py → anchor.py → assemble.py ../../build/tariffs.json
# 4) 분석·페이지
python3 scripts/analyze.py build
python3 scripts/build_smp.py <smp_xlsx_dir> build            # smpInLand_YYYY.xlsx, smpJeju_YYYY.xlsx
python3 scripts/build_sysload.py <계통부하.xlsx> build
python3 scripts/analyze_cost.py build
python3 scripts/build_monthly.py <월보_폴더(연도별 하위폴더)> build   # build_ref.py 다음에 실행
python3 scripts/build_regionmap.py build
python3 scripts/build_discount.py build
python3 scripts/build_contract.py <계약종별_판매실적_xlsx_폴더> build   # monthly.json·meta.json 다음
python3 scripts/build_fin.py <별도_재무상태표_PDF_폴더> <한국전력통계_폴더> build
python3 scripts/build_region.py <시도_xlsx> <시군구_xlsx> <한국전력통계_폴더> build   # monthly.json 다음
python3 scripts/build_resbins.py <2024폴더>,<2025폴더> build <복지할인_구간분포_폴더>   # tariffs.json 다음
python3 scripts/build_welfare_bins.py <2023폴더>,<2024폴더>,<2025폴더> build
python3 scripts/build_network.py build
python3 scripts/build_fuel.py <산정내역_txt_dir> build      # pdftotext -layout 결과(이미지 판은 OCR 후 MANUAL 반영)
python3 scripts/build_page.py ../ember-sim/index.html
```

## 데이터 기준과 보정

- 원자료: 계약종×본부×산업종×날짜, H01~H24 (kWh, **H01 = 00~01시**). 2016~2025년 29,690,283행. 2025년 파일은 영문 열 이름(CNTR_CLAS_NM·HDQR_NM·INDU_CLASS_NM·MR_YMD) → `scripts/ingest_csv.py`가 한글로 대응. 판매사업단(2024년 1행·2025년 167행, 약 2,400kWh)은 입력 시 지역코드 누락분이라 제외(담당 부서 확인).
- **수집장애일 58일**(2020년 3월 전후 41일 집중): 결측비중 > 3%, 행 수 < 이동중앙값 90%,
  또는 같은 날짜유형 11일 이동중앙값 대비 총량이 평일·토 0.8~1.2배 / 일·공휴일 0.6~1.4배 밖.
  해당 일은 같은 조합·같은 달·같은 날짜유형 유효일 평균곡선으로 대체. 일부 시간만 빈 행은 그 시간만 채움.
  그 달 유효일이 50% 미만인(드문드문 들어오는) 조합은 실제 들어온 행만 반영. 보정량은 연 +0.01~0.42%, 2020년 +2.8%.
- **표본 비중**: 시간별 데이터는 AMI(스마트미터) 부설 고객만 포함(담당 부서 확인, 시간별 추출은 AMI 고객만 가능). 2016~2020년 모양은 먼저 설치된 고객군 기준이라 전체와 다를 수 있음. 월보 판매량 대비 주택용 50→98%, 일반용 58→93%(2016→2025).
  산업용·교육용은 2024년부터 101~103%로 월보 초과(계약종 분류 차이 확인 필요). 크기 비교에는 확대계수, 모양 비교에는 정규화.
- 2023~2025년 수집장애일 없음(보정량 연 0.01%).
- 날짜유형: 평일 / 토요일 / 일요일·공휴일(`holidays.KR`, 대체공휴일 포함).

## 요금표

- 14개 판(2021.1.1 ~ 2026.4.16). 글자층이 온전한 6개 판은 직접 추출.
- 스캔본(2022.4·7·10, 2023.1, 2023.11)과 양식이 다른 판(2023.5, 2024.1·4)은 **2021.1과 2024.7 정확 판본 사이
  총 인상분을 앵커**로 두고, 단계별 인상분 경로를 문서 숫자(OCR/글자층)와 대조해 확정. 51개 묶음 모두 확정.
  확인된 단계: 2022.4 +4.9 / 2022.10 +7.4(을 대용량 +11.9·+16.6) / 2023.1 +11.4 / 2023.5 +8.0 /
  2023.11 산업용(을) +6.7·+13.5 / 농사용 분할 인상(1월 +3.8, 4·5월 +2.7).
- 2026.4.16 시간대 개편(산업용(을)·EV 4.16, 그 외 6.1): 경부하 22~08시, 최대부하 여름·봄가을 15~21시,
  겨울 9~12·16~19시. 산업용(을) 봄·가을 주말·공휴일 11~14시 50% 할인.
- 2021.1 이전(2016.12~2020.12)은 2021.1 전력량요금 + 5.3원(기후환경요금 분리 전)으로 재구성.

## SMP·계통부하

- 시간별 SMP 육지·제주 2016.1.1~2026.11.14 (결측: 제주 2020년 2일). 2024년부터 0원 이하 시간 발생(제주 2025년 152시간).
  파일의 '평균' 열은 단순평균과 달라 수요가중으로 보이며, 분석은 시간값을 직접 사용.
- 계통부하·태양광 2016.1.1~2026.10.6 (MW): 시장수요, 계통수요(= 시장 + PPA), 총수요(= 계통 + 자가용), KPX·PPA·자가용 태양광.
- 시간축 정렬: 사용량 표본합과 총수요의 시간 차분 상관이 동시각 0.968, ±1시간 0.70~0.73 → 1h·H01 모두 00~01시.

## 전력통계월보

- 2016.1~2026.9, 129개월. 한 호에 최근 약 13개월이 실려 호를 모아 시계열 구성. 시트 번호가 해마다 달라 이름 키워드로 탐색.
- 엑셀이 10월을 'YYYY.1'로 저장한 문제는 기준월에서 거꾸로 세어 해결. 같은 달 값이 호마다 다르면 최빈값(2023.1월호의 2022.1월 일반용 오기 보정).
- 월 합계와 한국전력통계 연간값 일치(판매량·수입 오차 0.000%). 2016.1은 연간값 − 2~12월(2016.1월호는 PDF).
- 판매수입 단위 백만원. 정산단가 중 CP 비중 8.0~15.4%(2025년 12.0%) → 시뮬레이터 '구입비 중 용량성 비중' 기본값.
- 시뮬레이터 판매량 확대는 대분류 × 월 단위, 연료비 이전액은 실제 분기 판매량.

## 복지할인

- 2021~2025 항목별 할인금액(억원)과 2025.12 대상 호수(천호). 항목 합 = 총계 검증.
- 시뮬레이터: 실적 보정을 '추정(할인 전) − 할인 = 실적 판매수입'으로 맞추고, 시나리오에서 할인 규모(%) 조정.
  사회복지시설(일반·주택·심야 합산)은 일반용 비중 입력(기본 50%), 기초 심야는 심야, 나머지는 주택용.
- 정액 한도형(장애인·다자녀·대가족 등)은 2021→2025 감소·정체, 정률형(사회복지시설·생명유지)은 요금 인상에 따라 증가.
- 구간별 분포(2023~2025, 216개 파일, 연도 폴더를 쉼표로 이어 입력): 구간 = 가구당 월 사용량(단일계약은 세대 평균). 총할인 = 필수사용량보장공제 + 200kWh이하감액 + 요금동결 + 복지할인,
  할인 후 = 할인 전 + 총할인 (전 행 검증). 연간 6,474억원(복지 5,714 = 실적표 주택용 항목의 98%), 월평균 354만 가구.
  요금동결 할인 = 2023년 주택용 인상분(21.1원/kWh)을 취약계층 약 365만 호에 월 313kWh까지 유예(2024.1 1년 연장, 가구당 월 최대 6,604원).
  실측 유예액 2024년 2,057억원(매월, 발표 계획 2,615억), 2025년 291억원(1~4월 청구분). 시뮬레이터 실적 보정에 실적표 외 감액으로 더함:
  2023 실측 2,127억(유예 1,666 + 200kWh 이하 감액 461, 정부 발표 유예 1,860억), 2024 실측 2,512억(유예 2,057 + 200kWh 이하 감액 455), 2025 실측 760억(291 + 469).
  2024→2025 총할인 7,947억 → 6,474억: 감소분 대부분이 유예 종료, 복지할인은 5,435억 → 5,714억.
  단일계약은 '할인 전 요금'이 비어 있어 할인율에서 제외. 가구당 할인은 사용량과 무관하게 월 1.5만원 안팎 → 할인율 101~200kWh 78% → 501~700kWh 13%.

## 판단 기준 (기본값 + 화면 선택)

| 항목 | 기본값 | 화면에서 고를 수 있는 것 |
|---|---|---|
| 판매·기타 비용 배분 | 고객 수(가로등은 kWh) — 계약종별 고객 수는 판매실적 실측 | 고객 수(전 계약종), kWh |
| 피크 기준 | 시장수요(태양광 차감) 상위 100시간 | 시장수요 300시간, 총수요 100·300시간 |
| 형평성 목표 | 정책 보조 분리(농사용·심야 + 복지할인) + 회수율 90~110% | 허용 범위만, 전 계약종 100%, 하한·상한 입력, 대분류/계약종 보기 |
| 회수율 기준 | 전체 평균 대비(계약종 회수율 ÷ 한전 전체 회수율) | 원가 대비 |
| 원가 기준 | 영업비용 + 금융원가(별도, 이자 등) | 영업비용, 적정투자보수(ROI) |
| 연료비 연동 판단 | 산식 기준(상한 없는 필요단가) | 규칙 기준(약관 ±5원 상한) — 누적 차이·용도별 영향·발견이 즉시 바뀜 |

  일반용 102.9%, 가로등 101.0%, 주택용 92.1%, 교육용 88.5%, 심야 77.4%, 농사용 52.4%.

  전체 평균 대비로 판단합니다. 영업비용만 원가로 보면 전체 회수율은 110.5%.
- 개선안 프리셋(시뮬레이터 '개선안 불러오기', 2025 판매량·원가, 2026.4.16 요금표):

  안 2 정책 외 계약종 회수율 균등화(약 113%, 수입 중립: 주택 +29.7, 교육 +37.1, 가로등 +18.8, 일반 +11.4, 산업 −16.4, 임시 −17.3원),
  안 3 지역별 요금제만(산업용 −10원 = −2.8조, 한전 회수율 106.9→103.7%, 영업비용 기준 110.5→107.2%).
- 연료비: 산식 기준 잔여 미회수 +16.1조원(최대 34.5조, 2023.3분기), 규칙 기준 고객 초과 부담 −13.7조원(2023.4분기 이후 −15.2조).

  금융원가 = 이자비용 + 외환·파생 손실(2016·2017 이자비용 비중 79·69%), 평균 금융부채 대비 2.8~4.7%(2025 3.3%, 2.87조원).

  나머지는 당기 이익(별도 순이익 7.2조원) = 재무 회복분. 2021~2023 별도 순손실 합계 34.2조원 ≈ 연료비 산식 대비 미반영 최대 34.5조원.


- 한전 영업정보 '계약전력구간별 판매실적' 2022~2025 연도별 xlsx(6만5천 행 제한으로 시트 2개 → 이어 붙임, 조회기간은 문자로 읽음).
- 대분류 × 월 판매량·판매수입·월말 고객호수가 월보와 전부 일치(최대 오차 0.00005%). 판매수입 = 기본 + 사용량요금(기후·연료 포함, 복지할인 후).
- 주택용저압+고압 → 주택용전력, '구 농사용(을)'(2023) → 농사용(을)저압, 중복 키 3행 합산.
- 시뮬레이터(기준 연도 2022~2025): 계약종 × 월 판매량으로 확대, 기본요금 = 요금적용전력 실측 × 단가, 배전 원가 kW = 요금적용전력 연평균,
  실적 보정은 계약종 단위(대분류 할인은 추정 비례 배분). 요금표 미산정 계약종(가로등(갑)·임시전력 일부)은 실적 수입 그대로.
- 2025 회수율(영업비용 기준): 일반용 105.9%(갑 저압 103%, 을 고압A 109%), 산업용(을)고압A 123%·B·C 130%, 교육용 86%, 농사용 54%.

## 지역 (시도·시군구, 전력자급률, 지역별 요금제)

- 시도 × 계약종 연간 2016~2025: 판매량 단위 MWh(머리말 kWh는 오기), 고객호수·요금적용전력은 12개월 합계. 월보 연합계와 일치(최대 0.01%).
- 시군구 × 계약종(판매량 kWh): 시군구 합계 = 시도(판매수입 기준 2개 조합 외 완전 일치). 황해북도(개성공단)·기타(매칭에러) 제외, 군위군 2023 대구 편입.
- 판매수입 = 기본 + 개편전 전력량 + 환경비용차감 + 기후환경 + 연료비조정 (전 행).
- 발전량: 한국전력통계 8-2(제88호 2018 ~ 제95호 2025, 2016·2017년판엔 표 없음). 전력자급률 = 발전량 ÷ 판매량, 2023년 값은
  에너지경제연구원 지역에너지통계연보와 일치(서울 10.4, 충남 213.6, 경북 215.6, 대전 3.1%). 2025: 경북 252%·전남 215%·충남 209% vs 대전 3%·서울 7%.
- 산업용 지역별 요금제 시나리오: 설계안(2026.8) 4개 광역 근사(서울 한강 이북 14구·경기 북부 10개 시군·인천 = 수도권 북부, 김포·양평은 남부 가정),
  권역별 인하폭(원/kWh) × 시군구 산업용 판매량. 최대 인하폭(1/10/15/18원) 기준 2025년 3.49조원(정부 추산 2.8조원은 11개 지역 차등 반영).

## 주택용 사용량 구간 분포

- 2024·2025년 월별 청구 144개 파일(연도별 폴더를 쉼표로 이어 입력). 구간 = 가구당 월 사용량(단일계약은 세대 평균), 총액 = 기본+전력량+기후+연료(복지할인 전).
- 요금표 검증: 구간 평균 사용량으로 누진 재계산 → 실제 기본+전력량과 월 ±0.1% 이내. 저압 전체·고압 종합계약 세대 = 저압 요금표,
  고압 단일·고압 일반·저압 단일 = 고압 요금표. 하계 누진 구간은 청구월 7월 48%·8월 99%·9월 56%에 반영(최소제곱 추정).
- 정제: 복지할인유형 '-전체-'로 뽑힌 파일은 복지할인 가구만 담기므로 직전 달 분포로 대체(2025.12 저압 일반은 재추출본으로 교체 완료).
  가구당 기본요금 > 1.5 × 7,300원인 비주거성 행 제외(2025.1~3 고압 종합 월 320~380GWh, 4월부터 사라짐).
- 분포 합계 = 월보 주택용 판매량의 91~96%. 시뮬레이터 '실측 구간 분포' 모드는 분포 모양을 고정하고 월 판매량으로 확대
  → 주택용 실적 보정계수 0.78(로그정규) → 1.02(2024·2025). 기준 연도 분포가 없으면 가장 가까운 연도 분포를 씀.
- 2024년은 비주거성 대량 행 없음. 누진 3단계 가구 비중: 하계 외 8.3%(2024) → 8.8%(2025), 8월 청구 34.3% → 33.9%.

## 한계와 다음 단계

- 기본요금은 대분류 요금적용전력을 계약종 평균일 최대부하 비율로 배분한 추정치.
- 월보의 판매 통계는 7개 대분류까지만 있어 갑·을·전압별 확대는 시간별 데이터 내 비중을 따름.
- 주택용 누진은 호당 사용량 로그정규 분포 가정 → 실적 보정으로 수준을 맞춤. 조합별 호수 확보 시 대체.
- 원가 배분: 영업비용 = 전력구입비(시간별 SMP 가중 + CP 비중만큼 피크) + 송전 적정원가(피크·kWh)
  + 배전 적정원가(배전이용요금 저압·고압 단가 × kW·kWh, 고압B·C 제외) + 판매·기타(나머지, 고객 수).
  선택 시 송배전 적정투자보수 가산(총괄원가 방식). 송전 추이표=결산연도, 배전 추이표=적용연도로 해석해 정렬.
  기본요금 kW는 계약종 평균일 최대부하(대리값). 계통부하는 2016년부터 KPX 실측(2016~2020분 추가 수령, 2021~ 기존 자료와 완전 일치).
- 임시전력(갑/을저압)·가로등(갑)은 요금표에 단가가 없어 미산정.
- 고압 선택요금(Ⅰ/Ⅱ/Ⅲ)은 별도 분석하지 않기로 결정 — 선택Ⅱ를 대표값으로 사용.

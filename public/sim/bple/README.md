# PRAS-BPLE — 전력수급기본계획 시뮬레이터

제1차(2002)부터 제11차(2025)까지 11개 전력수급기본계획의 수요전망·설비계획·전원구성을
원문 수치로 비교하고, 수요·예비율·전원구성·이용률 전제를 바꿔 설비 과부족과 발전량·
온실가스 배출을 다시 계산합니다.

`pras-der` 저장소에 편입하는 방법은 [`INTEGRATION.md`](INTEGRATION.md) 를 보세요.
단독으로 열어볼 때는 `public/sim/bple/index.html` 을 브라우저로 열면 됩니다.

## 산정식

제11차 전기본 「발전설비 계획 수립절차」를 그대로 따릅니다.

```
기준수요   = 모형수요 + 추가수요(첨단산업 + 데이터센터 + 전기화)
목표수요   = 기준수요 − 수요관리량
목표설비   = 목표수요 × (1 + 기준 설비예비율)
실효용량   = Σ (전원별 정격용량 × 피크기여도)
신규필요설비 = 목표설비 − 실효용량
발전량     = 정격용량 × 이용률 × 8.76
청정수소·암모니아 = 석탄발전량 × 암모니아혼소율 + LNG발전량 × 수소혼소율
배출량     = (석탄 순발전량 × 0.8384 + LNG 순발전량 × 0.3800) × 0.948
```

### 계수의 출처

| 계수 | 값 | 출처 |
|------|-----|------|
| 석탄 배출계수 | 0.8384 tCO₂eq/MWh | 11차 전기본, '20~'22년 발전기별 실적 평균 |
| LNG 배출계수 | 0.3800 tCO₂eq/MWh | 같음 |
| 전환부문 보정계수 | 0.948 | 아래 검증 참조 |
| 피크기여도 | 계획별 상이 | 각 계획 본문의 실효/정격 비율에서 역산 |
| 이용률 | 계획별 상이 | 각 계획의 전원별 발전량 ÷ (정격용량 × 8.76) |

보정계수 0.948 은 열병합·자가발전 배분 등으로 생기는 단순 곱셈과의 차이를 메우는 값입니다.
11차의 배출목표 두 지점에 맞춰 역산한 뒤, 세 번째 지점에서 독립 검증했습니다.

| 검증 지점 | 모델 | 계획 공표치 | 오차 |
|-----------|------|-------------|------|
| 11차 2030년 | 145.8 | 145.9 백만톤 | 0.1% |
| 11차 2038년 | 83.1 | 83.1 백만톤 | 0.0% |
| 10차 2036년 | 98.7 | 98.8 백만톤 *(11차가 인용한 10차 감축목표)* | 0.1% |

### 데이터 한계

- **제1차**는 PDF 글꼴에 ToUnicode 매핑이 없어 텍스트 추출이 되지 않습니다.
  페이지를 이미지로 변환해 표를 눈으로 읽어 옮겼습니다.
- **제6·7차**는 전원별 발전량 전망을 공표하지 않았습니다. 해당 계획의 목표연도
  전력소비량에 발전단 보정 1.11 을 적용해 총발전량을 잡고, 원전·재생e 는 기준
  이용률로 고정한 뒤 나머지 급전가능 전원에 균등 배분합니다. 화면에 `모형 추정`
  배지로 표시됩니다. **제9차**도 '34년 전원별 발전량이 없어 같은 방식입니다.
- **제1·4차**는 설비 표의 기준연도(2015·2022)와 발전량 표의 기준연도(2010·2020)가
  다릅니다. 이용률 역산에는 발전량 기준연도의 설비용량(`genCap`)을 씁니다.
- **제11차**는 양수 발전량을 '기타'에 합산해 공표하므로 수력·양수 행의 발전량이
  0 으로 표시됩니다.
- 계획 대비 실적 비교에서 1~9차는 전력시장 기준, 10·11차는 전력계통 기준으로
  전망했습니다. 두 기준 차이는 '23년 기준 4.7GW(전력계통 98.3 vs 전력시장 93.6)라,
  같은 기준끼리 비교하도록 맞췄습니다. 계절 기준이 다른 8·9차는 하계 계열을 씁니다.

## 데이터 구조

`data/plans.js` 는 전역 상수 여섯 개를 노출합니다.

| 전역 | 내용 |
|------|------|
| `SRC` | 11개 계획 공통 비교용 8개 전원 분류 |
| `ENGINE` | 피크기여도·이용률 기본값, 배출계수, 보정계수, 혼소율 |
| `ACTUAL` | 각 계획 본문에 '실적'으로 명시된 최대전력·설비용량 |
| `PLANS` | 차수별 계획기간·수요전망·예비율·설비·발전량·해설 |
| `DSM11` | 11차 수요관리 목표 16.3GW |
| `ADD11` | 11차 추가수요 ('38년 최대전력 증분) |

각 계획 항목의 주요 필드:

```js
{
  id: 11, name: '제11차', year: '2025.2',
  period: [2024, 2038], target: 2038,
  reserve: '22% (단기 20 / 중기 21 / 장기 22)', reserveNum: 22,
  peak:        { 2024: 101.0, ... },   // 목표수요 최대전력 (헤드라인 기준)
  peakWinter:  { ... },                // 동계 계열 (10·11차)
  peakSummer:  { ... },                // 하계 계열 (8·9차)
  peakBase:    { ... },                // 기준수요 (11차)
  reserveSeries: { ... },              // 계획 원문 연도별 설비예비율
  pc:   { renew: 11.1, coal: 98.2, other: 97.0 },  // 피크기여도 override
  blend: { nh3: 20, h2: 26.1 },        // 혼소율
  cap:  { nuclear: 35.2, ... },        // 목표연도 정격용량
  gen:  { nuclear: 248.3, ... },       // 목표연도 발전량 (없으면 null)
  genH2: 43.9,                         // 청정수소·암모니아 발전량
}
```

새 차수가 나오면 `PLANS` 배열에 항목 하나를 더하면 됩니다. 화면·차트·표는 모두 이
배열을 순회하므로 다른 파일은 건드릴 필요가 없습니다.

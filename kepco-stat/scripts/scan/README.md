# 스캔본(1962–1983년) 판독·교차검증 자료

제53호(1983년 실적)는 글자 층이 없는 스캔본이라, 아래 순서로 값을 확정했다.

1. `*.csv` — 제53호 원본 이미지를 사람이 읽듯 직접 판독해 옮긴 표.
2. `*_other.csv`·`*_e52.csv` — 다른 판(제52호·제54호)의 원본을 따로 판독한 값.
3. `verify.py` — 각 칸을 ① 다른 판(제52·54호)의 글자 인식(OCR) 결과, ② 다른 판을 따로 판독한 값과 대조하고,
   ③ 표 안의 산식(항목 합 = 합계, 영업수익 − 영업비용 = 영업이익, 자본 + 부채 = 자산 등)을 검사한다.
   산식이 맞는 행에서, 다른 판으로 확인된 칸과 산식으로 하나만 남는 칸만 받아들인다. 원자료 단수 차이 ±2는 허용.
   산식이 맞지 않는 행은 모든 칸이 다른 판과 똑같이 인쇄된 경우에만 받아들이고 `*.flags.json` 에 남긴다.
4. `*.accepted.json` — 받아들인 칸. `build_data.py` 가 이 파일만 읽는다.

## 원자료 불일치로 표시한 값 (두 판 이상에 같은 값으로 인쇄)

- 발전설비 1971년: 기력 2,034,500 + 내연력 265,265 + 수력 341,280 = 2,641,045 kW, 합계 2,628,045 kW.
  합계는 발전설비·발전실적 두 표와 제52·53호에 모두 같으므로 합계를 쓰고 화력 = 합계 − 수력(2,286,765 kW)으로 둔다.
- 송전 회선긍장 1966·1976년 계, 변전용량 1963년 계, 배전 지지물 1972년 계, 시도별 판매량 1980년 합계,
  시도별 수용가 1964·1970년 합계, 용도별 판매량 1969·1977년 합계(단수), 전력손실 1964·1966년, 1인당 판매량 1969년.

## 바로잡은 값

- 제53호 요소별 손익계산서 1983년 영업이익 627,730 → 672,730 (제54호, 제53호 기능별 손익계산서, 영업수익 − 영업비용).
- 제69호 1980년 154kV 변전용량 8,789,200 → 9,789,200 kVA (제52·53·54호, 전압별 합 = 계).
- 제69호 1984년 주택용 판매량 8,856,564 → 8,756,564 MWh (제54호 두 표, 용도 합 = 합계).

## 넣지 않은 것

- 제조업종별 판매량(옛 분류): 업종 구성이 1995년 이후 분류와 달라 이어 붙일 수 없다.
- 1972년 손익·재무상태: 제52호에만 실려 있어 다른 판과 대조할 수 없다.

판독 방법의 정확도는 제54호의 1984년 행을 같은 방법으로 읽어 전산 자료(제69호)와 비교해 확인했다(일치).
제69호와 겹치는 연도(송전·변전·배전 설비 1979–1983년)는 모두 제69호 값과 같았다(위의 제69호 1980년 오식 1건 제외).
